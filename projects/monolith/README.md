# Project: Monolith Starter

จุดเริ่มต้นก่อนแตกเป็น microservices ใช้ฝึก Clean Architecture / DDD / Hexagonal ใน [books/04-golang](../../books/04-golang/README.md) บนโครงสร้างเดียวที่ยังไม่ซับซ้อนเรื่อง distributed system

## สถานะ

โครงไว้ก่อน — ยังไม่มีเนื้อหา/โค้ดจริงในรอบนี้

## เป้าหมาย (แผน)

- ระบบ e-commerce แบบง่าย (catalog + order) ในโปรเจกต์เดียว ใช้ PostgreSQL เป็นฐานข้อมูลหลัก
- วางโครงสร้างตาม Clean Architecture ให้พร้อมแตกเป็น service ย่อยในอนาคต
