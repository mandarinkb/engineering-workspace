# Scripts

สคริปต์อัตโนมัติสำหรับ setup, provision, และ utility งานต่างๆ ในหลักสูตรนี้ เช่น สคริปต์ตั้ง local dev environment, สคริปต์ backup, หรือ security scan เบื้องต้น

## แนวทาง

- สคริปต์ shell ทั่วไปเก็บที่นี่โดยตรง (ผูกกับ [books/03-linux](../books/03-linux/README.md))
- สคริปต์ Python ที่ซับซ้อนกว่า ให้เก็บใน [source-code/python/](../source-code/python/README.md) แล้วลิงก์มาที่นี่
- ทุกสคริปต์ควรมี comment สั้นๆ บอกวัตถุประสงค์และวิธีใช้ที่ด้านบนไฟล์

## สถานะ

โครงไว้ก่อน — ยังไม่มีสคริปต์จริงในรอบนี้
