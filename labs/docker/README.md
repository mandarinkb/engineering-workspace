# Lab: Docker

แล็บฝึกปฏิบัติสำหรับ [books/07-docker](../../books/07-docker/README.md)

## สถานะ

โครงไว้ก่อน — ยังไม่มีเนื้อหาแล็บจริงในรอบนี้

## แนวทางที่วางแผนไว้

- เขียน Dockerfile สำหรับแอป Go ง่ายๆ ด้วย multi-stage build ให้ image เล็กที่สุด
- ตั้งค่า Docker Compose รัน service + PostgreSQL + Redis พร้อมกัน
- ทดลอง network mode และ volume persistence ด้วยตัวเอง
