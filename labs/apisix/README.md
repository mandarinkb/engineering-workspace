# Lab: APISIX

แล็บฝึกปฏิบัติสำหรับ [books/10-apisix](../../books/10-apisix/README.md)

## สถานะ

โครงไว้ก่อน — ยังไม่มีเนื้อหาแล็บจริงในรอบนี้

## แนวทางที่วางแผนไว้

- ตั้งค่า Route/Upstream ให้ APISIX route ไปยัง service ตัวอย่าง
- เปิดใช้ plugin: jwt-auth, limit-count
- ทดสอบ rate limit และ consumer แยกสิทธิ์กัน
