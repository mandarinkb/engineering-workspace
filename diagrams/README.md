# Diagrams

ไดอะแกรมประกอบเนื้อหาใน [`books/`](../books/) และ [`projects/`](../projects/) เช่น architecture diagram, sequence diagram, ER diagram, network diagram

## แนวทาง

- ใช้ format ที่ diff ได้ใน git เท่าที่ทำได้ เช่น [Mermaid](https://mermaid.js.org/) (`.mmd`/embed ใน markdown) หรือ [PlantUML](https://plantuml.com/) แทนไฟล์ภาพ binary
- ตั้งชื่อไฟล์ให้สื่อว่าเป็นไดอะแกรมของหัวข้อ/โปรเจกต์ไหน เช่น `ecommerce-architecture.mmd`, `payment-saga-sequence.mmd`

## สถานะ
